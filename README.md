# フォント比較アプリ MVP

## アプリ概要

複数のフォントを、同じ文章・同じ表示条件で並べて比較できるWebアプリです。見た目、文字幅、字形のバランス、用途や属性をカード形式で確認できます。

## 主な機能

- 左側のチェックボックスによるフォント選択
- フォントカードの一覧表示
- 文字サイズの変更
- 太さの変更
- 行間の変更
- 字間の変更
- 通常表示
- 固定マス表示
- 実幅枠表示
- 詳細表示
- KaTeX数式フォント専用ビュー
- 51種類の数式用例とLaTeXコピー
- レスポンシブ表示
- Memo Nexusから渡された用途・現在のフォント・比較文章を表示する連携モード
- 用途別の推奨表示、フォント選択、検証済みURLによるMemo Nexusへの戻り
- 戻り先を利用できない場合のフォント設定コピー

## 使用方法

フレームワークやビルド作業は不要です。Windows環境のVS Codeやエクスプローラーから、index.html をブラウザで開いて確認してください。KaTeX数式フォントの表示にはインターネット接続が必要です。

ローカルファイルとして開いた場合、JavaScriptの実行自体は可能ですが、将来の機能追加時にローカル実行制限が生じる可能性があります。

## Memo Nexus連携

Memo Nexusから次のURLパラメータを指定すると連携モードで起動します。

- `mode=memo-nexus`
- `target=body|heading|code`
- `scope=global|note`
- `currentFontId`: 現在選択中の登録済みフォントID
- `returnUrl`: 選択結果を返すMemo NexusのURL
- `sample`: 比較文章（最大700文字）
- `memoId`: メモ個別設定の対象ID

連携モードでは用途への推奨を先に表示し、選んだフォントを「Memo Nexusで使用」で戻せます。戻り先はMemo Nexusの公開URLとlocalhost／127.0.0.1の開発URLだけを許可します。戻り先を確認できない場合は遷移せず、「フォント設定をコピー」を利用できます。通常のパラメータなし起動とKaTeXビューは従来どおりです。

この比較は登録済みの基礎情報と目視プレビューによるものです。ブラウザが実際に描画したフォントを自動判定・断定する機能ではなく、対応言語情報にも「未確認」が含まれます。

## フォント表示に関する注意

- 閲覧環境に対象フォントがインストールされていない場合、別フォントへフォールバックする可能性があります。
- フォントファイル自体はこのリポジトリに含めていません。
- カードに表示する対応言語や属性の一部は、MVP段階では手動定義です。
- 言語対応、ライセンス、配布元URLを確認できない場合は「未確認」と表示し、「未対応」とは断定しません。
- 現段階ではPythonやcmapによる自動解析結果を画面へ連携していません。
- Web利用可否やライセンスは未確認項目を含みます。

## 確認方法

1. index.html をブラウザで開く
2. 初期状態で3種類のカードが表示されることを確認する
3. サイドバーのチェックを切り替え、カードの表示が変わることを確認する
4. 文字サイズ・太さ・行間・字間・表示モードを切り替えて確認する
5. 画面幅を狭くして、2列または1列へ変化することを確認する
6. ヘッダーの「KaTeX 数式フォント」を選び、数式用例とフォント群の説明を確認する
7. 用例のコピーボタンを押し、LaTeXがコピーされることを確認する
